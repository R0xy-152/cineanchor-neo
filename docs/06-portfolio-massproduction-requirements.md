## 一、背景

- Spike `05`（2b）通过验收：确定性 Blender base → Seedance 出火花/氛围 → 文字确定性合成，**观感更佳、无闪烁、无主体偏移**（已写入 `ADR-007`）。
- 但这是**单次**成功（一个素材 + 一条提示词），**普适性尚未验证**——可能是该素材/提示词的运气。
- 北极星：用最快路径拿到能进作品集的视频。当前半手动流程（CC 出 base + 提示词，启鸣 自己跑 Seedance）成本低、已跑通，是验证普适性最划算的载体。
- 同时启鸣 提出量产中需要方便地调「模型位置/方向/旋转」和「环境灯光」。经确认：这些先做**代码→配置的解耦**，启鸣 自己改 JSON 即可，**前端 UI 留作后续 loop**。

## 二、目标

一箭三雕：**填作品集** + **验证 2b 普适性** + **把 transform/灯光解耦成干净的 JSON 参数面**。

1. 用 2b 流程半手动量产 2–3 个**不同武器、不同运镜**的片段。
2. 在多样素材上验证 2b 的两个头号风险是否复现：**帧间一致（无闪烁）** 与 **主体无偏移**。
3. 审计并暴露一套干净的 JSON 参数面，使启鸣 无需改代码即可逐片调整模型位置/方向/旋转与环境灯光。

## 三、范围

### CC 做什么
1. **参数解耦审计**：核对模型「位置 / 方向 / 旋转」与「环境灯光」当前是已在 project JSON 可调，还是部分写死在代码里；补齐写死项，使其全部可经 JSON 调整。
2. **参数表文档**：为上述每个参数给出——JSON 路径、含义、取值范围/单位、默认值、一个示例值。供启鸣 照着改。
3. **量产 N 个 base 视频**（N=2–3，见确认问题）：沿用 `05`/`ADR-007` 规格——**text-free、particle-free、glints 关闭**，Seedance 友好格式（1080p 或 720p，24 或 30fps，H.264 MP4，3–5s），输出本地路径。
4. **每个 base 配套 Seedance 提示词**：遵循 `ADR-007` 的「声明已烘焙内容(保留) → 增强已有氛围 → 仅新增火花」结构，可直接复制粘贴。

### CC 不做什么
- 不做前端 UI（本期）。
- 不接 Seedance API（仍由启鸣 手动跑），不查接入方式。
- 不改主体几何、相机路径、文字流程（保持确定性）。

### 启鸣 做什么
- 指定（或交由 CC 自选）2–3 个**差异化**的武器 + 运镜组合。
- 把每个 base + 提示词丢进 Seedance 出 C。
- 对每个 C 做人工验收（观感 / 火花 / 主体 / 帧间一致）。
- 自行改 JSON 验证参数面是否真的可控。

## 四、普适性验证维度

刻意拉开差异，才能压测普适性，而非重复同一种成功：

- **武器差异**：形状/体量/主色不同（影响 Seedance 对主体的锚定与火花配色）。
- **运镜差异**：至少覆盖两种 camera move（如 dolly 推进 vs 环绕/转台），看相机锚定在不同运动下是否仍守住主体。

## 五、验收标准

| # | 标准 | 判定方式 |
|---|------|---------|
| 1 | 解耦完整：位置/方向/旋转/灯光均可经 JSON 调整，无需改代码 | CC 报告 + 参数表 |
| 2 | 改 JSON 真生效：改一个值重渲，画面对应变化（可控性） | 启鸣 手动改值验证 |
| 3 | 参数表齐全：每参数含路径/含义/范围/默认/示例 | 启鸣 审阅文档 |
| 4 | 量产 N 个 base：text-free、particle-free、格式合规、本地路径输出 | 启鸣 抽查 + 格式核对 |
| 5 | 每个 base 配套合规提示词（保留+增强+新增结构） | 启鸣 审阅 |
| 6 | **2b 普适性（核心）**：多样素材经 Seedance 出片后，多数仍满足「无主体偏移 + 无闪烁」 | 启鸣 逐片人工判定 |
| 7 | 输出全部文件路径供启鸣 retrieval | CC 报告 |

> #6 是本 loop 的核心结论项：决定 2b 是「普适可推进工程化」还是「依素材而定、需约束」。

## 六、ADR 评估（§8）

- 本 loop 是**执行 + 验证**，不是新方向决策 → **不新开 ADR**。
- 普适性结论以**带日期更新**形式追加到 `ADR-007`：
  - 多样素材普遍成立 → 确认 2b 普适，为后续工程化/前端铺路。
  - 个别素材出现闪烁或主体偏移 → 记为**已知限制**（哪类素材易失败、对应回退策略），ADR-007 主体仍立。
